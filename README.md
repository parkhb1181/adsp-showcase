# ADsP 합격 패턴 · 코드 발췌

ADsP 자격증 시험에서 출제 빈도가 높은 부분만 남겨, 최소 학습으로 합격선(60점)을 넘게 하는 학습 웹앱입니다.
혼자 기획·개발·운영하고 있고, 2주 만에 배포한 뒤 네이버 검색 상위 노출로 사용자가 200명에서 5,000명이 됐습니다.

- 서비스: https://adsp-app.vercel.app (Web + Android TWA)
- 스택: Next.js (static export) · Supabase (Auth · Postgres · Edge Functions) · PortOne(KG이니시스) · Vercel
- 기간: 2026.05 배포, 운영 중

원본 레포는 결제와 앱 서명 키가 얽혀 있어 비공개입니다. 여기에는 **왜 그렇게 설계했는지 설명할 수 있는 부분만** 발췌했습니다.
면접에서 원본 화면 공유가 필요하면 보여드릴 수 있습니다.

## 일하는 방식

- 코드 대부분은 Cursor·Claude Code로 작성했습니다. 대신 **왜 그렇게 했는지를 주석으로 남기게** 하고, 사고가 났으면 그 기록도 같이 둡니다. 사례 2와 3이 그 기록입니다.
- 클라이언트가 결정할 수 있는 값(금액·날짜·만료)은 서버에서 다시 정합니다. 정적 빌드라 anon key가 번들에 들어가는 구조여서, "믿지 않는다"가 기본값입니다.
- 실패해도 학습은 끊지 않습니다. 사용량 증가가 실패하면 카운트가 한 번 덜 오르는 쪽을 택했습니다.

## 발췌 범위

- 설명에 필요한 부분만 잘라 왔고, 주석은 읽기 쉽게 일부 다듬었습니다. 로직은 원본 그대로입니다.
- 문항 데이터, 앱 서명 키, 사업자 정보, API 키, PG 계정 정보는 넣지 않았습니다.
